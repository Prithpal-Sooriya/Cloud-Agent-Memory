# explain-video overview

A short overview of this skill, made with the skill itself. The video is attached to the pull request description. The mp4 is not in git.

## What the video shows

- A change or a system becomes one short video you can send.
- Depth is a choice: overview (diagrams only), standard (a few snippets), or a deep dive when you ask.
- Nothing renders until a plan is approved. Changes are sorted into covered, mentioned, or skipped.
- Each line keeps real spelling on screen and a separate spoken line. A local Kokoro voice reads the script. Captions use the screen spelling.
- After approval, Videowright renders the frames and a frame from each scene is checked. The file can stay in a folder or be attached to a pull request. It is not committed.
- Beside that path: a math engine (Manim), a strict script style, and a pronunciation list.

## How this cut was made

- Engine and style: Videowright, Motion Engineering
- Depth: overview, 4 scenes, about 63 seconds, no code on screen
- Script style: natural
- Voice: local Kokoro 82M, `af_heart`, 24 kHz
- Check: the local speech check matched every spoken line
